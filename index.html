Linux: conceptos básicos

Fundamentos

¿Qué es Linux?

Linux es, en sentido estricto, un kernel (núcleo): el programa que se comunica con el hardware y reparte la memoria, el procesador y los dispositivos entre los demás programas. El 25 de agosto de 1991, el estudiante finlandés Linus Torvalds anunció públicamente que trabajaba en él.

Cuando se habla de un sistema Linux se alude al kernel junto con las herramientas del proyecto GNU, iniciado por Richard Stallman el 27 de septiembre de 1983, y otros programas. Por eso algunas personas lo llaman GNU/Linux.

Es software libre y de código abierto: el kernel se distribuye bajo la licencia GPL versión 2, que permite usarlo, estudiarlo, modificarlo y compartirlo.

Capas de un sistema Linux

Un sistema Linux se puede imaginar como una pila de capas. Las aplicaciones y la shell (el intérprete de comandos) se apoyan en bibliotecas y herramientas GNU; estas piden servicios al kernel, y el kernel es el único que controla directamente el hardware.

Distribuciones y paquetes

¿Qué es una distribución?

Una distribución reúne el kernel Linux, herramientas GNU, un gestor de paquetes y, normalmente, un entorno de escritorio, todo listo para instalar. Cada una tiene sus propios objetivos: estabilidad, novedades, facilidad de uso o personalización.

Distribuciones populares y su gestor de paquetes

Gestión de paquetes

Un paquete es un programa empaquetado con la información que necesita para instalarse. El gestor de paquetes los descarga de repositorios, resuelve sus dependencias y los mantiene actualizados. En las distribuciones de la familia Debian se usa apt: 

                        sudo apt update # actualiza la lista de paquetes disponibles
sudo apt install git # instala un paquete
sudo apt remove git # desinstala un paquete
sudo apt upgrade # actualiza los paquetes instalados

sudo ejecuta el comando con privilegios de administrador, necesarios para instalar o quitar programas del sistema.

La terminal

Estructura de directorios

Linux organiza todo en un único árbol que empieza en la raíz, /. No existen letras de unidad como C:; los discos adicionales se montan dentro del árbol.

/
Raíz del sistema: de ella cuelga todo lo demás.
/home
Carpetas personales de cada usuario.
/etc
Archivos de configuración del sistema y de los programas.
/bin y /usr
Programas y bibliotecas del sistema.
/var
Datos que cambian con el tiempo, como los registros (logs).
/tmp
Archivos temporales.
/dev
Archivos que representan dispositivos, como discos y terminales.
/proc
Sistema de archivos virtual con información de los procesos y del kernel.
/root
Carpeta personal del superusuario (administrador).

Comandos esenciales

La terminal ejecuta una shell, que lee los comandos que escribes y los ejecuta. Estos son los que más se usan al empezar:

Comandos básicos de la terminal
Comando Función Ejemplo
pwd Muestra el directorio actual. pwd
ls Lista el contenido de un directorio. ls -l
cd Cambia de directorio. cd /etc
mkdir Crea un directorio. mkdir proyectos
cp Copia archivos o directorios. cp notas.txt copia.txt
mv Mueve o renombra archivos. mv notas.txt docs/
rm Elimina archivos; no pasan por una papelera. rm copia.txt
cat Muestra el contenido de un archivo. cat notas.txt
grep Busca texto dentro de archivos. grep "error" registro.log
man Abre el manual de un comando. man ls
sudo Ejecuta un comando con privilegios de administrador. sudo apt update

Una sesión de ejemplo:

                        usuario@linux:~$ pwd
/home/usuario
usuario@linux:~$ mkdir proyectos
usuario@linux:~$ cd proyectos
usuario@linux:~/proyectos$ ls
usuario@linux:~/proyectos$ cd ..
usuario@linux:~$

Pulsa Tab para autocompletar nombres y ↑ para recuperar comandos anteriores.

Permisos de archivos

Cada archivo tiene permisos de lectura (r), escritura (w) y ejecución (x) para tres grupos: el propietario, el grupo y los demás. El comando ls -l los muestra al principio de cada línea: 

                        -rwxr-xr-- 1 usuario grupo 1024 oct 17 10:30 script.sh

El primer carácter indica el tipo (- es un archivo). Luego vienen tres bloques: rwx para el propietario, r-x para el grupo y r-- para los demás. Con chmod se modifican: 

                        chmod u+x script.sh # añade ejecución al propietario
                            chmod 754 script.sh # equivale a rwxr-xr--

En la forma numérica, cada permiso vale un número: lectura 4, escritura 2 y ejecución 1. Se suman por bloque, así que 7 es rwx, 5 es r-x y 4 es r--.
